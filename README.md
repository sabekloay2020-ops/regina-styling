# Regina · שאלון סטיילינג אישי

שאלון היכרות ללקוחות חדשים: 25 שאלות ב־7 פרקים. בסוף הלקוח שולח את התשובות בוואטסאפ.

- **האתר החי:** https://sabekloay2020-ops.github.io/regina-styling/
- **הגרסה ב־Claude:** https://claude.ai/artifact/7KzbqYxiNN4sJP8wz51o8h

## מה יש בתיקייה

| קובץ | מה זה |
|---|---|
| `index.html` | הדף עצמו: השאלות, העיצוב והקוד. כל שינוי נעשה כאן. |
| `assets/` | הלוגו (גרסה כהה ובהירה), תמונת הרקע, תמונת התצוגה לשיתוף בוואטסאפ והאייקון |
| `source/` | תמונת המותג המקורית, בלי שינויים |
| `build.sh` | בונה את האתר החי מתוך `index.html` |
| `docs/` | האתר החי ש־GitHub Pages מציג. לא עורכים כאן ידנית, `build.sh` כותב אותו. |

## איך מעדכנים את האתר

1. עורכים את `index.html`.
2. מריצים `./build.sh`.
3. עושים commit ו־push. האתר החי מתעדכן תוך דקה או שתיים.

## מספר הוואטסאפ

בתחילת הסקריפט ב־`index.html` יש את השורה `const WHATSAPP_NUMBER = '';`.
כותבים בה את המספר בפורמט בינלאומי, בלי `+` ובלי 0 בהתחלה, למשל `'972501234567'`.
כשהשורה ריקה, וואטסאפ נפתח עם ההודעה מוכנה ומבקש לבחור למי לשלוח.
